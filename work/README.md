# FlyRank Capstone Paper Website

Static, Vercel-ready research paper site for the FlyRank ML capstone.

## Deploy on Vercel

1. Import the GitHub repository.
2. Set **Root Directory** to `work`.
3. Framework preset: **Other** (static site).
4. Build command: leave empty.
5. Output directory: `.`.
6. Deploy.

The site has no backend and no build step. It uses the generated SVG charts already present in `assets/charts/`.
